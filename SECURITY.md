# Security policy

## Supported versions

Security fixes are made against the latest release published on [crates.io](https://crates.io/crates/shft).

## Reporting a vulnerability

Please do not open a public issue for security problems. Instead, report them privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**.

Useful details include the affected version, a description of the impact, and steps or a sample file that reproduce it. Since `shft` decodes untrusted image files, crashes, hangs or excessive memory use triggered by a crafted input are in scope.

You should receive a response within a week. Once a fix is released, the advisory will be published with credit to the reporter unless you prefer otherwise.
